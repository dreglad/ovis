### Added
- A Halcyon theme, dark only, from the Halcyon VS Code and Hyper themes: `#1d2433` content,
  `#171c28` chrome, the `#ffcc66` accent, and Halcyon's terminal foreground, cursor, selection and
  sixteen ANSI colours.

### Changed
- A dark theme may now set its terminal's sixteen ANSI colours; one that does not keeps xterm's
  defaults, as every dark theme did before.
